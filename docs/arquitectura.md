# Arquitectura DuocDev (MVP)

- **Frontend**: Flutter (pantallas estudiante + profesor simulado).
- **Backend**: Node.js + Express con persistencia JSON local.
- **IA**: Modo demo local y camino preparado para OpenAI desde backend.
- **Flujos clave**:
  - Estudiante: aprender por cursos/lecciones/desafíos.
  - Profesor: cargar material y publicar ejercicios.
