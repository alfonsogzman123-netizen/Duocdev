# Flujo estudiante

`Inicio → Cursos → Curso → Lección → Desafío → Resultado → Práctica inteligente → Perfil`

## Inicio

Muestra saludo, continuidad, nivel, XP, meta diaria, racha, práctica inteligente y accesos rápidos.

## Ruta y curso

La ruta ordena cursos por nivel y muestra estado, progreso, XP estimado, lecciones y disponibilidad de práctica docente.

## Lección y desafío

Cada microlección incluye objetivo, explicación, ejemplo de código, tip docente y acceso al Tutor IA. El desafío entrega feedback inmediato, pista y XP.

## Práctica inteligente

Lista ejercicios publicados por profesor o datos demo si no hay backend. Cada ejercicio muestra curso, dificultad, XP y estado.

## Perfil

Resume carrera, Duoc UC, nivel, XP, racha, progreso, insignias y acceso al modo profesor.
