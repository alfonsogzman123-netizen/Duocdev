# DuocDev - Guía para agentes

## Descripción
DuocDev es un MVP educativo con app Flutter (estudiante/profesor simulado) y backend Node.js/Express.

## Estructura
- `lib/`: app Flutter.
- `backend/`: API REST MVP.
- `docs/`: documentación técnica interna.

## Comandos
### Flutter
- `flutter clean`
- `flutter pub get`
- `flutter analyze`

### Backend
- `cd backend`
- `npm install` (o `npm.cmd install` en Windows)
- `npm run dev`

## Reglas de trabajo
- No eliminar funcionalidades existentes.
- Mantener UI visible en español.
- No hardcodear claves/API keys.
- Mantener diseño premium oscuro actual.
- Probar cambios antes de terminar cuando el entorno lo permita.
